# Serviços

Esta camada coordena casos de uso e integrações sem acoplar regras de negócio a
componentes ou ao provedor de dados.

A Tarefa 6.2 adicionou somente funções puras de normalização, validação e
categorização interna de erros de autenticação. Cadastro, Login, proteção de
rotas e Logout serão implementados apenas nas tarefas correspondentes.
