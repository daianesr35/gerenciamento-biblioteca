# Instruções permanentes do projeto

## Contexto

Este projeto é um Sistema Web para Gerenciamento de Biblioteca Pessoal.

A especificação funcional oficial está em [`docs/SDD-sistema.md`](docs/SDD-sistema.md). Toda implementação deve seguir integralmente essa especificação.

## Diretrizes de desenvolvimento

- Implementar, em cada tarefa, somente o escopo solicitado.
- Não acrescentar requisitos, funcionalidades ou alterações fora do escopo da tarefa.
- Antes de modificar qualquer arquivo, analisar o estado atual do projeto e os arquivos relevantes.
- Preservar as regras de negócio, os fluxos e os critérios definidos na especificação funcional oficial.
- Executar testes e verificações aplicáveis ao escopo alterado.
- Ao final de cada tarefa, informar todas as alterações realizadas, os arquivos criados ou modificados e o resultado dos testes e verificações.

## Controle de versão

- Não criar commits sem solicitação explícita.
- Não realizar push sem solicitação explícita.
